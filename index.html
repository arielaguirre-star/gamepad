DESACTIVAR REQUERIMIENTO DE PIN / CONTRASENA EN MAKECODE

La API Web Bluetooth de los navegadores no soporta el intercambio de PIN. Para evitar la carita triste:

  1. Abre tu proyecto en MakeCode micro:bit.
  2. Haz clic en el engranaje ⚙️ (Configuración del Proyecto).
  3. Selecciona Project Settings.
  4. Cambia la opción de Bluetooth a: No Passkey Needed.
  5. Descarga de nuevo el archivo .hex a tu micro:bit.
