SOLUCIÓN DE CONEXIÓN ANDROID Y MICRO:BIT

Pasos para resolver fallos de escaneo y sincronización desde teléfonos móviles

PASOS OBLIGATORIOS PARA CONECTAR DESDE ANDROID
  • 1. Activa la Ubicación (GPS): Android exige GPS activado en el sistema para que Chrome pueda realizar búsquedas de dispositivos Bluetooth Low Energy. Si el GPS está apagado, la lista de dispositivos aparecerá en blanco.
  • 2. Cambia el Filtro de Nombre: Por defecto el mando busca dispositivos llamados ar1. Abre la configuración (botón XBOX) y selecciona el perfil "Dispositivo Genérico BLE (Sin Filtro)" para ver la micro:bit con su nombre original (BBC micro:bit [...]).
  • 3. Revisa los Permisos de Chrome: Ve en tu celular a Ajustes -> Aplicaciones -> Chrome -> Permisos y activa Ubicación y Dispositivos Cercanos.
  • 4. Desvincula la micro:bit del Bluetooth del Celular: Si la emparejaste en los Ajustes de Bluetooth de Android, dale a Olvidar Dispositivo. Web Bluetooth requiere conectarse directamente desde la web y no desde los Ajustes del teléfono.
¿POR QUÉ SUCEDE ESTO?

Los navegadores web (Web Bluetooth API) NO pueden autenticar la clave PIN encriptada requerida por defecto por micro:bit. Al conectar con PIN, el micro:bit espera una confirmación de seguridad que el navegador no puede enviar. Tras 5 a 10 segundos, el micro:bit aborta la conexión por timeout y sufre un desbordamiento de memoria RAM intentando guardar la clave fallida, mostrando la carita triste y reiniciándose.

1 SOLUCIÓN DEFINITIVA: Desactivar la clave PIN ("No Passkey Needed")

Para solucionar esto de inmediato, debes configurar el proyecto de MakeCode para que no pida PIN ni emparejamiento previo:

  1. Abre tu proyecto en makecode.microbit.org.
  2. Haz clic en el engranaje ⚙️ (Configuración) en la esquina superior derecha.
  3. Selecciona Project Settings (Configuración del Proyecto).
  4. Busca la opción de seguridad y selecciona: "No Passkey Needed: Anyone can connect via Bluetooth".
  5. Vuelve a cargar el archivo .hex en tu micro:bit.

2 ALTERNATIVA (Si deseas mantener el PIN)

Si obligatoriamente necesitas usar un PIN, debes emparejar el micro:bit a nivel del Sistema Operativo ANTES de abrir la aplicación web:

  • Abre la configuración de Bluetooth de tu PC (Windows/Mac) o Smartphone.
  • Empareja el micro:bit e ingresa el PIN de patrones ahí.
  • Una vez enlazado por el sistema operativo, abre esta web e inicia la conexión normalmente.

bluetooth.startUartService()

bluetooth.onBluetoothConnected(function () {
    basic.showIcon(IconNames.Yes)
})

bluetooth.onBluetoothDisconnected(function () {
    basic.showIcon(IconNames.No)
})

bluetooth.onUartDataReceived(serial.delimiters(Delimiters.NewLine), function () {
    let cmd = bluetooth.uartReadUntil(serial.delimiters(Delimiters.NewLine))
    if (cmd == "F") {
        // Mover Robot Adelante
    } else if (cmd == "B") {
        // Mover Robot Atrás
    } else if (cmd == "L") {
        // Giro Izquierda
    } else if (cmd == "R") {
        // Giro Derecha
    } else if (cmd == "S") {
        // Detener Motores
    }
})
def on_connected():
    basic.show_icon(IconNames.YES)
bluetooth.on_bluetooth_connected(on_connected)

def on_disconnected():
    basic.show_icon(IconNames.NO)
bluetooth.on_bluetooth_disconnected(on_disconnected)

def on_uart_data():
    cmd = bluetooth.uart_read_until(serial.delimiters(Delimiters.NEW_LINE))
    if cmd == "F":
        pass # Avanzar
    elif cmd == "S":
        pass # Detener
bluetooth.on_uart_data_received(serial.delimiters(Delimiters.NEW_LINE), on_uart_data)

bluetooth.start_uart_service()
